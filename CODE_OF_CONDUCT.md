# Code of Conduct

## Our Commitment

This project aims to provide a respectful, welcoming, and collaborative environment for everyone. All contributors are expected to treat others with courtesy and professionalism.

## Expected Behavior

Contributors are encouraged to:

* Be respectful and considerate of others.
* Communicate in a constructive and professional manner.
* Accept feedback gracefully.
* Help maintain a positive and inclusive environment.
* Follow the project's coding conventions and documentation standards.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, discrimination, or personal attacks.
* Offensive or inappropriate language.
* Intentionally disrupting discussions or collaboration.
* Sharing confidential or personal information without permission.
* Any behavior that creates an unsafe or unwelcoming environment.

## Coding Standards

When contributing to this project:

* Write clean, readable, and well-structured code.
* Use meaningful variable and function names.
* Keep functions and modules focused on a single responsibility.
* Document new features where appropriate.
* Test changes before submitting them.
* Write clear and descriptive commit messages.

## Scope

This Code of Conduct applies to all project spaces, including the source code, documentation, issue discussions, pull requests, and any other project-related communication.
