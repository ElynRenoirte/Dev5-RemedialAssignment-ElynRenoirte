# Changelog

All notable changes to the Neighborhood Watch App will be documented in this file.

## [Unreleased] - 2026-07-29
### Added

- Initial project structure.
- Docker environment for frontend, backend, and MySQL.
- Express backend setup.
- Frontend container using Docker.
- MySQL database container.
- Environment configuration using .env.
- Basic project documentation.
- Git repository with initial branching strategy.

## [v0.1.0] - 2026-07-31

### Added

- Created database
- Created routes
- Created controllers 
- Created services 
- Created repositories

### Changed

- Tested with Postman and fixed the POST route not working

## [v0.2.0] - 2026-08-01

### Added

- Created HTML layout with map placeholder, report form and recent reports
- Created map with Leaflet
- Added login system

## [v0.3.0] - 2026-08-02

### Added

- Data visualization of the reports
- Added more places to the named places list
- Report system

### Changed

- Login now requires name and password
- Changed password length
- Users can now choose longitude and latitude by clicking on the map; the map is only available for certain neighborhoods
- "Most reported areas" statistic now shows actual place names instead of coordinates
